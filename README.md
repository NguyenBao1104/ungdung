### Chạy chương trình


Bạn cần chạy lệnh này trên 3 cửa sổ terminal và nhập số cổng trong file Port.py

```shell
python Server.py
```

Sau đó bạn chạy chương trình của khách hàng bằng lệnh sau:

```shell
python Client.py
```
